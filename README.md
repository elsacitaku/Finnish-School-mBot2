# Finnish School mBot2
## What is mBot2?
The **mBot2** is a small robot that we can program in ICT class
## What can mBot2 do?
- It can show *messages* on its screen.
- It can change its LED lights to red, green or blue.
## What is CyberPi?
CyberPi is the part of mBot2 that runs the program and controls the robot.
## Three important features of mBot2
1. A screen that can show text.
2. RGB LEDs that can light up in different colours.
3. Sensors that help the robot detect what is around it.
## Why do we use mBot2 in ICT?
We use mBot2 to practice Python and see what our code does.
